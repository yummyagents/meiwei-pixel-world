## 这次改了什么

四位特工现在都有两套外观：

1. **角色选择卡和选择预览**：使用你提供的四张照片头像。
2. **第三人称方块小人**：根据照片里的服装、发型、帽子和小道具重新制作。

## 照片处理

- 原图复制到 `assets/images/characters/`
- 每张裁成 480×480 的头部/半身照，压缩为 22KB～37KB
- 角色卡和选择预览都直接使用同一张照片
- 保留原来的 Emoji 作为没有照片时的备用

## 已知限制

- 第三人称镜头在角色后方，通常看到的是背影；角色的正面由角色卡照片展示。
- 3D 小人采用游戏统一的方块比例，不会 1:1 复刻黏土照片的圆润轮廓。
- 角色外形是代码实时搭出来的，不依赖外部模型文件。
