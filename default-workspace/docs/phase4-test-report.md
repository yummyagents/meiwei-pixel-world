## 已经实际验证的存档流程

- 真正等待 **12 秒自动保存**触发，并确认存档写入了：
  - 当前角色
  - seed
  - 玩家位置和视角
  - 快捷栏内容和选中格子
  - 两个被修改的方块（一个空气、一个砖块）
  - 新手任务 3/3
  - 当时 6 只小动物的位置（第六阶段扩展后为 12 只，并新增牛、马、驴和村民）
- 自动保存时，HUD 出现“已自动保存”。
- 刷新整个页面后，首页显示“魔法小女巫的世界”和保存时间。
- “继续上次世界”能直接恢复：
  - 角色
  - 世界 seed
  - 玩家位置
  - 快捷栏
  - 任务进度
  - 破坏成空气的方块
  - 放置的砖块
  - 小动物数量和位置
- “开新世界”会生成新 seed、清空方块修改和任务。
- 首页按钮文字会根据有没有存档自动变化。
- 损坏的 localStorage 存档不会让首页崩溃，也不会显示继续按钮。
- 代码里还加入了页面刷新/关闭前的兜底保存；本轮主要用“自动保存后刷新续玩”验证整条流程。

## 已经实际验证的导入导出

- 点击“导出存档”会下载有效 JSON 文件。
- 导出的存档包含正确的 seed、角色、修改方块和任务数据。
- 导入错误文件会显示：
  - “这不是有效存档，请选择《美味特工队》的存档文件。”
- 错误导入不会覆盖原本正常的存档。
- 导入有效存档后：
  - 首页角色信息更新为薯条厨娘
  - 继续游戏后角色正确恢复
  - seed 保持不变
  - 导入数据中的任务、方块和动物数据也通过了格式校验

## 已经实际验证的作品集

- 未有照片时，P 打开作品集显示空状态。
- P 打开作品集会暂停游戏，P 再按一次会继续。
- C 能拍下当前 3D 画面并加入作品集。
- 照片写入 localStorage，刷新页面并继续世界后仍然存在。
- 作品集里的照片显示角色、群系和时间。
- 照片可以删除，删除后空状态重新出现。
- 390px 手机上作品集无横向溢出，照片可以完整显示。
- 存档导出不会包含照片；照片单独保存在本机。

## 测试中修好的问题

1. 首页底部“继续上次世界”在 844×390 横屏下被挤成竖排文字 → 横屏隐藏装饰场景并让按钮自然换行，已复测。
2. 手机存档卡片的说明文字继承居中 → 改成左对齐。
3. 游戏底部快捷键提示条从屏幕中间开始、右侧被裁掉 → 补上水平居中，C/P/Esc 全部可见。
4. 打开作品集时“拍照成功”提示会挡住“回去玩”按钮 → 打开作品集时自动隐藏旧提示。

## 测试环境的限制

- 无头 Chromium 会拒绝鼠标指针锁定；自动测试走的是“提示 + 拖动视角”的备用路线，真实浏览器仍需点击画面确认锁定。
- 自动化测试无法“听到”音效，只确认音频代码执行时没有报错。
- 照片最多 9 张，使用浏览器 localStorage；如果空间不足会提示先删照片。
- 存档只保存在当前浏览器，不会上传到云端。
- 天气切换 T、小地图 M、回出生点 R 和手机虚拟摇杆尚未加入，属于下一阶段。
