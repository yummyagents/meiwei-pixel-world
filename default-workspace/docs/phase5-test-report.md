# 第五阶段测试报告

测试日期：2026-10-28  
测试方式：Playwright Chromium 实际启动游戏、按键、触摸摇杆、鼠标拖动、传送观察和刷新

## 总体结果

- 第五阶段新功能与手机触控：**42 / 42 通过**
- 正常流程无控制台 error、未捕获异常或 404

## 已实际验证

### 天气

- T 从晴天切到下雨，HUD、天气提示和环境状态都改变
- 再按 T 切到下雪，HUD 显示“下雪”
- 再按 T 能回到晴天
- 雨天有雨丝、天空变暗；雪天有白色雪花
- 天气写入存档，读档后能恢复
- 雨天/雪天不会破坏移动、任务、动物和保存流程

### 小地图（N）

- N 打开身边小地图，再按 N 关闭（M 在第七阶段升级为全区域大地图）
- 小地图 Canvas 真的绘制出像素：180×180 上有 32400 个不透明像素
- 地形颜色来自实际群系和高度
- 玩家位置有朝向箭头，小动物用金色点显示
- 地图更新有节流，不会每帧重画

### 回出生点

- 走远后按 R 回到出生点，位置误差小于 1.2 格
- 显示“回到出生点啦！”
- 小地图和天气不受影响

### 手机触控

- 手机识别为 touch-mode，显示摇杆、破坏、放置、跳跃按钮
- 鼠标提示条在手机上自动隐藏
- 摇杆能真的移动玩家，实测移动超过 5 格
- 拖动画面能改变视角，yaw 改变约 0.38 弧度
- 跳跃按钮能跳起
- 破坏按钮能挖掉准星方块，放置按钮能放回方块
- 手机显示了触屏版新手提示（不是键盘说明）
- 页面禁止双指缩放，摇杆和画布使用 `touch-action: none`
- 390px、320px、横屏 844×390 下摇杆、按钮和快捷栏不重叠
- 手机按住跳跃按钮也能在水里游上来

### 低性能自动降档

- 手机软件渲染 FPS 较低时，等待约 4.5 秒后：
  - 渲染距离从 3 降到 2
  - 区块从 49 降到 25
  - 显示“手机有点辛苦，我把远处调小一点，会更流畅啦。”
- 降档只执行一次，不会每帧重复弹提示

## 测试中修好的问题

1. 手机端没有触屏新手说明 → 新增手机版提示。
2. 横屏首页按钮被挤压 → 重新排列横屏首页。
3. 快捷键提示条没有水平居中，右侧被裁掉 → 已居中。
4. 水下滤镜元素没有写进 HTML → 补上并用实际潜水测试。
5. 手机按住跳跃不能持续游泳 → 增加按住跳跃游泳。

## 已知限制

- T/R 仍是键盘快捷键；手机端优先提供移动、视角、破坏、放置和跳跃。M/F/V 在第七阶段加入了手机快捷按钮。
- 小地图不保存开关状态，重新进游戏默认关闭。
- 天气和低性能降档在同一个游戏会话内不会自动暂停。
