# 第七阶段测试报告：飞行、视角和世界地图

测试日期：2026-10-28  
测试方式：Playwright Chromium 实际按键、触摸按钮、鼠标点击、世界地图 Canvas 像素读取和截图

## 总体结果

- 第七阶段新功能：**40 / 40 通过**
- 第七阶段结束时全项目回归：**416 / 416 通过**
- 后续加入四位特工外观专项 20 项和美味科技城专项 13 项检查，当前总计 **449 / 449**
- 正常流程无控制台 error、未捕获异常、404 或请求失败

## 自由飞行（F）

- 起初是地面第一视角
- F 打开飞行，HUD 出现“飞行模式”
- 飞行时按住空格从 Y 13.0 上升到 15.2
- 按住 Shift 从 15.2 下降到 14.2
- 松开按键后悬停，不会继续往下掉
- 再按 F 关闭飞行，重新受重力影响并落到地面
- 飞行状态提示会同步消失

## 第一 / 第三视角（V）

- V 切到第三视角
- 第三视角能看到小特工的方块身体、手臂和腿
- 镜头位于角色后上方，实测距离约 4.56 格
- 第三视角下仍能用准星挖方块
- 站在洞穴墙边时镜头自动缩短到约 3.4 格，镜头位置在空气方块中
- 再按 V 恢复第一视角，角色模型隐藏
- 第三视角镜头碰撞使用逐段方块检测，不会穿墙

## 世界地图（M）

- M 打开世界地图，同时暂停游戏
- 地图覆盖出生点周围约 **900 × 900 格**
- Canvas 尺寸 640 × 640
- 地图真的画出了多种地貌：实测 1471 种颜色、409600 个不透明像素
- 地图图例包含：
  - 平原、樱花林、丛林、沙漠、雪地/雪顶、海洋/河流、高山
- 地点标记包含：
  - 村庄
  - 洞穴入口
  - 瀑布
  - 废弃矿井
  - 雪山
  - 风车
- 玩家位置有白色朝向箭头和“你在这里”
- 地图会显示最高雪山的位置
- 地图卡片在 1440×900 下完整显示，“继续探险”按钮可见
- 390px 手机上地图卡片也完整可用
- Esc 能关闭地图并恢复游戏
- 再按 M 能关闭地图
- 地图底图会缓存，第二次打开只重绘玩家和标记

## 小地图（N）

- N 打开身边小地图，N 关闭
- 小地图仍然显示附近地形、动物点和玩家朝向
- 小地图 Canvas 仍是 180×180，已绘制 32400 个不透明像素
- M 和 N 分工明确：M 看大区域，N 看身边

## 手机快捷按钮

手机右上角新增一排 3 个按钮：

- 🗺️ 世界地图
- 🕊️ 飞行
- 👁️ 第一/第三视角

实测：

- 手机按钮能打开飞行
- 手机按住跳跃按钮能在飞行中上升，实测 Y 13.0 → 14.9
- 手机按钮能切第三视角并显示角色
- 点地图按钮能打开世界地图，地图有 6 个地点标记
- 手机世界地图可以关闭并恢复游戏
- 手机新流程无 JS 错误、无 404

## 测试中修好的问题

1. 第三人称镜头碰撞测试最初只检查距离，没有检查镜头是否在方块里 → 增加相机坐标和镜头方块检查。
2. 世界地图卡片在 900px 高度下把“继续探险”按钮挤出视口 → 缩小地图到 500px 并压缩卡片间距。
3. 世界地图关闭键和 N 小地图的提示文字混淆 → 操作说明、底部快捷键条和 README 全部更新为 M 大地图、N 小地图。
4. 快捷键条变长后，在中等宽度会换行压到快捷栏 → 1280px 以下自动收起。
5. 地图底部比例文字贴边被裁 → 上移并重绘。
6. 手机教程没有提到右上角新按钮 → 增加手机教程说明。

## 已知限制

- 世界地图以出生点为中心显示 900×900 格，不是无限世界的完整地图；世界仍可继续向外探索。
- 飞行状态和视角模式不会写进存档，重新打开游戏回到地面第一视角。
- 手机飞行用跳跃按钮上升，关闭飞行后靠重力下降；没有独立的手机“下降”按钮。
- 自动测试环境会拒绝鼠标锁定，第三人称仍用拖动视角的备用路线测试。
