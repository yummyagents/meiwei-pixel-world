## 已经实际验证的项目

### 启动流程

- 首页标题、副标题、欢迎语正常显示。
- “下一步：选特工”和“操作说明”能点击。
- 角色选择页有 4 张卡片。
- 未选择时“开始冒险”隐藏；选择后出现。
- 点击卡片会高亮。
- 点击“开始冒险”会出现加载进度，完成后进入游戏。
- 不是白屏，canvas 尺寸正常，HUD 正常。
- 自动弹出新手提示，关闭后可继续游戏。
- 暂停菜单的“继续冒险”有效。

### 电脑操作

- W / A / S / D 分别控制前、左、后、右。
- ↑ / ↓ / ← / → 分别控制前、左、后、右。
- 同时按 W + D 能斜向移动。
- Shift 奔跑速度明显快于走路。
- 空格可以跳跃，并能落回地面。
- 鼠标左键拖动可以转动视角。
- 方向键不会让网页上下滚动。
- Esc 暂停；暂停时按 W 不会移动。
- H 可以打开和关闭新手提示。
- 玩家不会穿过树干。
- 从高空落下会落在地面，不会穿过地面，也不会掉到世界下面。

### 世界和 HUD

- 初始加载 49 个区块。
- 走远后会加载新区块，并且远处旧区块会卸载（测试后仍为 49 个附近区块）。
- HUD 显示 FPS、坐标、群系、时间、天气、已加载区块数。
- 出生点默认在平原。
- 同一个 `?seed=12345` 的出生点和风车位置在两次加载中完全一致。
- 桌面、手机竖屏、手机横屏都没有横向溢出。

### 错误处理

- 浏览器禁用 WebGL 时显示中文错误、技术小提示和“重新尝试”按钮。
- 游戏模块加载失败时显示中文提示。
- 资源加载失败后点击“重新尝试”，会刷新并自动继续所选角色，能恢复到游戏。

## 测试环境的限制

- 无头 Chromium 会拒绝鼠标指针锁定，所以自动测试实际走的是“锁定失败提示 + 按住左键拖动视角”的备用路径。真实的桌面浏览器中，点击画面会调用标准 Pointer Lock API；建议部署后再用实际 Chrome/Edge 点一下确认鼠标锁定。
- 自动化测试使用 SwiftShader 软件渲染，截图里显示的 FPS 会偏低；这不代表有独立显卡的电脑表现。
- 手机当前阶段保证页面、HUD、新手提示和菜单布局正常；虚拟摇杆、放置/破坏按钮会在后续移动端阶段加入。
