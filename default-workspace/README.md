# 美味特工队：像素方块世界

一款给小朋友玩的 3D 像素方块探索游戏。纯静态网页，不需要账号、后端或付费服务。

## 现在可以玩到什么

### 地表世界

- 9 种群系：平原、沙漠、海边、樱花林、雪地、海洋、河流、高山、丛林
- 海洋、河流、湖泊会自动灌水，可以真的潜下去游泳
- 高山有石头山坡和雪顶；丛林有高高的丛林木、丛林叶和垂下来的藤蔓
- 村庄：小房子、玻璃窗、红屋顶、水井、农田小麦、小路、火把和宝箱
- 村庄里有 3 位村民；草地上有兔子、小鸡、小羊、奶牛、小马和小驴
- 风车地标、树木、小花、云朵、昼夜和天气继续保留

![村庄和村民](docs/screenshots/village.png)

![丛林和海洋](docs/screenshots/jungle.png)

### 地下世界

- 自然洞穴：地下有空腔、隧道、苔藓、发光浆果、矿石和硫磺晶块
- 繁茂洞穴：苔藓块、杜鹃叶、发光浆果
- 硫磺洞穴：硫磺块、玄武岩、硫磺晶簇
- 废弃矿井：木支架、深色木板地面、铁轨和宝箱
- 深处的硫磺洞穴会生成一小片熔岩池
- 出生点附近有可以走进去的展示洞穴入口，里面有繁茂、硫磺和矿车轨道
- 地下会显示“地下洞穴”群系

### 飞行、视角和世界地图

- F 打开/关闭自由飞行：空格上升，Shift 下降，松手悬停
- V 切到第三视角，能看到自己的小特工背影；再按回第一视角
- 第三视角镜头会自动避开墙和地形，不会钻进方块
- M 打开大世界地图：覆盖出生点周围约 900×900 格
- 地图显示平原、樱花林、丛林、沙漠、雪地、海洋/河流、高山
- 地图标出村庄、洞穴入口、瀑布、废弃矿井、风车、雪山和美味科技城
- N 保留身边的小地图，继续显示附近动物和朝向

### 任务、存档和照片

- 新手三步任务：走 10 步、放 1 个方块、靠近 1 只小动物
- 每 12 秒自动保存；刷新后可以继续
- 存档包含角色、seed、位置、快捷栏、任务、12 只动物、天气和修改过的方块
- 支持导出 JSON、导入存档、开新世界
- C 拍照、P 作品集；照片保存在本机浏览器
- Esc 暂停、H 打开/关闭新手提示
- M 打开 900×900 格的大世界地图，N 打开身边小地图
- F 自由飞行，V 第一 / 第三视角切换
- R 回出生点
- 手机支持虚拟摇杆、拖动视角、破坏/放置/跳跃按钮，并会自动降低渲染距离
- 手机右上角可以直接点地图、飞行和视角按钮

## 默认世界小指南

默认种子是 `20261028`，出生在平原。用 HUD 的坐标可以找到：

- 出生点东边（X 变大）约 8 格：地下洞穴入口
- 再往东约 20 格：村庄和村民
- 西边约 50 格：海洋和河流
- 东边约 60 格：丛林
- 沿着东边的河继续走约 100 格：瀑布
- 瀑布东侧的台地：美味科技城（青色地图标记，也可以按 F 飞过去）
- 更远的地方有 20 格以上的雪山

开新世界时会随机换 seed，所以每次的位置会不一样。

## 本地运行

不要直接双击 `index.html`，因为 ES Module 需要通过 HTTP 打开。

```bash
cd 项目文件夹
python3 -m http.server 8000
```

然后访问 <http://127.0.0.1:8000/>。

## 部署到 GitHub Pages

1. 把整个文件夹上传到 GitHub 仓库。
2. 在仓库 Settings → Pages 中选择 `Deploy from a branch`。
3. 选择主分支和根目录（`/`）保存。
4. 等一会儿，用 Pages 给出的网址打开即可。

所有资源都是相对路径，Three.js 已放在 `assets/vendor/`，不需要 CDN。

- 性能不足时会自动把渲染距离从 3 降到 2，并显示提示

## 已知限制

- 存档和照片只保存在当前浏览器，不会上传到云端；换设备请用“导出存档”。
- 作品集最多保存 9 张照片。
- 自动测试环境会拒绝鼠标锁定，仍用“点击提示 + 拖动视角”的备用路线；真实浏览器建议点击画面锁定鼠标。
- 手机端提供移动、视角、建造、地图、飞行和视角切换按钮；T 天气和 R 回出生点仍是键盘快捷键。
- 飞行状态和第一/第三视角不会写进存档，重新打开游戏会回到地面第一视角。
- 世界地图以出生点为中心，范围约 900×900 格；世界本身可以继续向外探索。
- 美味科技城在出生点东边约 100 格，目前没有传送门，需要跑过去或按 F 飞过去。
- 地形是程序生成的像素风世界，不是《我的世界》官方内容。
